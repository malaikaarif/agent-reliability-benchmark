# Working Rules

- `main` = stable, working code only
- Each person works on their own branch: `malaika-dev`, `iqra-dev`
- Never push directly to `main`  merge via Pull Request on GitHub
- Pull latest `main` into your branch before starting new work each session:
  git checkout main
  git pull
  git checkout your-branch-name
  git merge main
- Commit often with clear messages (e.g. "add langgraph adapter", not "update")
